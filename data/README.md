# Data

`ergo_simple_shoulder_moment_balanced.csv` is the supplied illustrative dataset used by every tutorial and script.

It contains one observation in each reach bin for 14 participants. The variables are participant identifier, sex, reach distance, shoulder moment, reach bin, and several versions of the reach variable used for centering and scaling demonstrations.

Readers do not need to generate the dataset. The original simulation code is retained in `optional/Generate_Illustrative_Data.R` solely to document how the illustrative values were created.
